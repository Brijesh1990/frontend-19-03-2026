# what is promises in javascript ? 

1. javascript promises is an object that links to in producing of code or consuming of code to performed any task there we used js promises 

2. js promises is an object that is performed some operations to handel asynchrounous in very easy way.

3. js by default performed any operation in async

# promises executed any operations in 2 way....

**producing the code**
```
any task or operations will performed and take some times to execute that called producing of the code
``` 
**consuming of code**

```
any task or operations will performed and wait for its result that called consuming of the code

```

# promises operations 

- promises operation devided in some parts to completed any task 

a) Pending : 

```
promises start with by default pending states that meanse process does not start if process will start so operations or state go inside of completed
```


b) fulfilled : 

```
A promises start from a pending states if the process or operation is successfully completed that is called fulfilled if any error occured while completing any operations it should be go inside of rejected

```



b) rejected : 

```
A promises start from a pending states if some error is occured its go inside of rejected operations

```
