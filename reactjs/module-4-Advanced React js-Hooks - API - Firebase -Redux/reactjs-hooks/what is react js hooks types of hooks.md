# what is react js hooks ? 

1. React js hooks are simple function that can introduce in React js 16.8.0
2. React js hooks are used to adding some services 
3. React js hooks are used to start to support React js 16.8.0 version
4. React js hooks in no more support in class based components 
5. React js hooks are most of support with functional based components
6. React js are used to provides some features just like State , lifecycle,  Methods , Context, Ref, Performance optimized and many more etc
7. React js hooks are used to call API data | fetch API data | applied many more effects in app via hooks 


# types of hooks used in React js ? 

1. useState()     : Manage components of state and update data via state
2. useEffect()    : Handel some side effects inside of app
3. useContext()   : Access context data in app
4. useRef()       : store references and mutable values from user input data of forms
5. useReducer()   : manage some complex state data 
6. useMemo()      : Memoize calculated values of data 
7. useCallBack()  : Memoize function  
8. useId()        : generate a unique ID of data
9. useLayoutEffect() : run effects before browser paint
