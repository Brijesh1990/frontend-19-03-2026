# what is props in react js 

1. props stands for properties used as function parameter
2. props pass in function as parameter
3. props provides immutable objects can not be changed data one components to another
4. props pass data parent to child 

   **examples**

     A => B  
5. props is an object pass in function as parameters 
6. props also used to pass data from parent to child components 
7. props pass in function as parameter and used in jsx as properties
